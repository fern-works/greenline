# The greenline guide

Describe the work to your coding agent. greenline gives it engineering
methods, contextual guidance, and durable records to use across sessions.
You keep control of scope and consequential choices.

Skills work locally with Codex and Claude Code. When configured, guidance
is retrieved from a provider for each request; an outage is reported as an error.
Explicitly unconfigured repositories work with skills and repository evidence.
Your decisions and work evidence remain in the repository.

## Where to start

1. [Quickstart](./quickstart.md): install and ask for your first change.
2. [The pipeline](./pipeline.md): how larger work moves from intent to evidence.
