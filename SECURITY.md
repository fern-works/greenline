# Security

Report a vulnerability in greenline, its published package or this
repository by email to admin@fernworks.dev, with the affected version and
the steps that show it. Do not open a public issue for it. You will get an
acknowledgement, and a fix reaches the package through a release; the
release notes name the report without naming you unless you ask.

The package publishes from this repository under npm's trusted publishing
with provenance: every published version carries an attestation naming the
repository, the commit and the workflow that built it, which `npm audit signatures`
verifies.
