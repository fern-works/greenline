# TDD: the practice's mechanics

This page holds where tdd's work lands in the workspace and the commands it runs, which `SKILL.md` names by their nouns. Read it with `SKILL.md` when the work lands in the workspace.

## Where its work lands

Each run of the focused command during the loop, red, green or a rerun made only to read why a test failed, goes through `greenline check -- <command>`, so the change's checks record it.
