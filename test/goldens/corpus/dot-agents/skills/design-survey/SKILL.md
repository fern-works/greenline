# Design survey

The survey reads an interface a repository already has into its home: what the code and the rendered pages hold, measured where it can be, written as DESIGN.md and the interface rulings once the owner confirms it. Start it where the workspace names interface roots and holds no DESIGN.md, or when the owner asks for the interface's system to be written down.

Before the first source is read, read [method.md](method.md): the mode, the order of the trace, the instrument, the sheet, the confirmation and the report.

## Handoff

Consumes: the repository's interface roots, its source and its rendered pages; the owner's answers through cards
Produces: DESIGN.md, the interface rulings and the survey's sheet, confirmed by the owner
Next: frame, under the mode the owner approves, for the change that writes the home; otherwise none, the survey's findings staying in the reply
