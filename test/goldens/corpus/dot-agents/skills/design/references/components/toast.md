# Toast

Read this page when the change shows a toast, a snackbar or any passing notice.

- **Announcing.** A toast is announced through a polite status region that already stands, empty, in the page; focus never moves to it, and an urgent problem tied to no field uses an alert.
- **Timing.** A toast that carries an error or an action stays until it is dismissed. A timed toast lasts at least five seconds and pauses on hover and focus, and nothing critical lives only in a timed toast.
- **Words.** An undo toast names the object and the past verb, with an Undo action; success carries no "successfully" and no exclamation.
- **Placement.** It overlays one clear edge, top or bottom, without moving the layout, and several toasts queue or replace one another.
- **Motion.** A toast is an occasional surface: standard, short motion, and a celebration is a style default to avoid.

## The checked rules

The registry's rules for this page's facets, each with its tier; the interface check runs them on the files you write, and a reviewer cites them by their ids.

- `live-region-status`, floor: An asynchronous status reaches assistive technology through a live region or a status role.
- `toast-timing`, reflex: A toast carrying an error or an action does not dismiss itself, and a timed toast pauses on hover and focus.
