# Footer

Read this page when the change builds or changes a site's footer. No source covers the footer alone; these rules gather what several do.

- **End on a scene.** A footer closes the page: the name set at full width, an inverted echo of the first screen, a closing scene, or one quiet line. Four equal columns of links is the default to avoid, and "All rights reserved" a template line.
- **Shapes to deal.** A mast, a statement, a colophon block, a newsletter first (on a page about subscribing only), a closing letter, or index columns.
- **Contents.** Privacy and terms links live here; practical facts are set in the text face at a readable size, on the page's anchor lines; the pictures' credits line stands here where the page shows found pictures.
- **Room.** A footer padded to the viewport's height is a hole.
- **Landmark.** It is the page's footer landmark, and a sticky footer or banner has matching scroll padding at the bottom.
