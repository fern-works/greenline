# Anatomy

anatomy is the habit for an explanatory figure of a concept, asked for by the owner, at whatever step the work is in: a mechanism of the code such as a cache key, a pool, a retry or a pipeline, or a figure for the project's docs or site. It is never made or remade unasked, and nothing is offered: on the owner's ask a fresh agent builds it, naming its size with the time for a Hero or an Epic, and an Epic waits for the owner's choice of size.

Greenline's paths and commands for this skill stand on its references page, [references/greenline.md](references/greenline.md): read it when the work lands in the workspace.

Before the figure is sized, read [method.md](method.md): where it lands, the one idea, the workflow, the setup and the craft rules.

Durable output: an explaining figure's page under `.greenline/visuals/<id>/` with its manifest; a figure for the docs or site where the owner places it.
