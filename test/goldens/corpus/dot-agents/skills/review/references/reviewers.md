# Starting the reviewers

The builder reads this page at the independent depth, where fresh agents review: regular's one and careful's two.

## Start the reviewers

Start the reviewers the depth gives one after another, each a fresh agent started through the harness's delegation, inheriting none of your conversation and never a fork of it. You never write a reviewer's brief. For each reviewer run `greenline brief --change <id> --step review --round <n> --intent "<your intent paragraph>"`, `<n>` the reviewer's number or the round's, with `--axis standards` for the first and `--axis spec` for the second where the depth gives two agents. It writes the one brief every fresh agent gets (`.greenline/ledger/README.md`, "The brief and the relay note") from the record to `.greenline/ledger/<id>/brief-review-<n>.md`, its first line the command's mark: the change record's front matter, the acceptance, the change's id, the path of the report, `.greenline/ledger/<id>/review-<n>.md`, and the pointer to the reviewer's brief, [brief.md](brief.md), which the reviewer alone reads whole with the reference files it names; then review's extras, your intent and the axis. It prints the file's path: start the reviewer with that path and nothing else. Never open, copy, diff or derive a brief file, one the command wrote for you included: a read of one is a finding for the next review, and `greenline status` reports a brief file the command did not write (GL0408). Give nothing else: not your other sections, not your diagnosis, not an earlier reviewer's findings. A reviewer starts no agent of its own. Wait for each report before starting the next; no reviewer runs beside the conversation.
