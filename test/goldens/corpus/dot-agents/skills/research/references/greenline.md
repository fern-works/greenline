# research: the practice's mechanics

This page holds where research's work lands in the workspace, which `SKILL.md` names by its nouns. Read it with `SKILL.md` when the work lands in the workspace.

## Where its work lands

Inside a change, frame starts you with the one brief every fresh agent gets (`.greenline/ledger/README.md`, "The brief and the relay note"), the accepted topic as its extra, and waits for your report before it starts the next researcher. Write your report under `.greenline/tmp/<id>/research-<n>/` and file it with `greenline research report <file> --change <id> --topic R<n>`, which writes `.greenline/ledger/<id>/frame-research-<n>.md`, `<n>` the topic's number, its first line `<!-- generated by the research start: report <n> -->`; never write it there by hand, and the frame section cites it. Keep every fetched text, an unpacked tarball and a scratch file in `.greenline/tmp/<id>/research-<n>/`, the change's working files, never under the user's home or the host's temporary directory. With no change open, the answer and its sources go in the reply and no file is written.
