# Diagram Design

diagram-design is the habit, a default, for the moment a durable diagram would serve a change, a plan or a decision: a standalone HTML or SVG file saved in the change's folder of the workspace's visual home beside its manifest, a plan's under its planning change, and linked from the record or the document it illustrates. It is made only on the owner's ask, offered once per change at the caps: a fresh agent draws it with the skill's brief; a quick sketch that lives in the reply belongs to show-me, and a state chart drawn of the code can be checked with the start `verify-formally`.

Greenline's paths and commands for this skill stand on its references page, [references/greenline.md](references/greenline.md): read it when the work lands in the workspace.

Before the first diagram, read [method.md](method.md): its record, the effective style guide, the philosophy, the selection of pattern and type, and the rest of the method.

Durable output: .greenline/visuals/<id>/, each diagram beside its manifest <slug>.visual.json, linked from the record or the plan document it illustrates; made only on the owner's ask.
