# Architecture survey: the practice's mechanics

This page holds where architecture-survey's work lands in the workspace and the commands it runs, which `SKILL.md` names by their nouns. Read it with `SKILL.md` when the work lands in the workspace.

## Where its work lands

The survey's report is `.greenline/tmp/<id>/architecture-review-<timestamp>.html`, in the working files, the id a date and a slug as a change's is; a change that takes a finding up copies it into its folder, `.greenline/ledger/<id>/`. The map's snapshot, which architecture-map writes, is `.greenline/map/snapshot.json`, and the work guide that names the knowledge homes is `.greenline/WORK.md`.
