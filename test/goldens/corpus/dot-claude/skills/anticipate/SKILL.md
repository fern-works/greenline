# Anticipate

Anticipate attacks a change's plan before the build: it states the claims the build would rest on and has a fresh reading try to disprove each one, so a hidden failure mode is found while changing course is still cheap. It changes the plan only where a finding requires it and records each change in its section; a finding that would reopen a choice the owner made goes back to the owner. It never builds: the build step takes the plan as anticipate leaves it.

Before the first claim is attacked, read [method.md](method.md): the reach of the cycle, the claims worth attacking, the five steps and the red flags.

## Handoff

Consumes: the change record's frame and plan sections in .greenline/ledger/<id>.md, and when the work splits the plan directory's spec.md and tickets.md
Produces: the anticipate section of .greenline/ledger/<id>.md, the one line none at the modes that skip it, and otherwise the claims attacked and the findings reconciled, citing the agent's report .greenline/ledger/<id>/anticipate-1.md at the independent depth; any change the findings made to the plan, recorded in that section; the reply alone when asked for by name with no change open
Next: the next step of the change's mode
