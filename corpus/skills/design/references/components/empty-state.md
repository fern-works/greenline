# Empty state

Read this page when the change shows a place with nothing in it yet, or nothing matching.

- **Words.** An empty state says what the place is, how to fill it, and gives one next action; a filtered empty state names the query and offers to clear the filters. Nothing that must persist lives there.
- **Values.** A true zero prints in the normal style; a missing value is a grey dash, never at full size; a raw "undefined", "null" or "NaN" never shows.
- **The frame stays.** An empty section keeps its frame and header and adds one sentence across the whole block; an empty chart is still drawn.
- **The first run.** It keeps the frame and title, puts the first action where the data will appear, and shows setup's true progress; an empty side card shows reference data rather than a blank box.
- **Tone.** Warm but not playful, with no emoji; an illustration belongs only to a rare, first-time moment.
- **Native.** Placeholders hold the layout while loading, and the empty view appears only once loading has finished empty.
