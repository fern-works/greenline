# Constraint-driven development: the practice's mechanics

This page holds where constraint-driven-development's work lands in the workspace and the commands it runs, which `SKILL.md` names by their nouns. Read it with `SKILL.md` when the work lands in the workspace.

## Where its work lands

The decisions book is `.greenline/DECISIONS.md`, where the bar stands when the repository keeps no decision home of its own and which the floor guard reads by default. The guard runs as a check through `greenline check -- node <guard> --bar <path>`, its `--bar` naming the file that holds the bar where the decision home is the repository's own.
