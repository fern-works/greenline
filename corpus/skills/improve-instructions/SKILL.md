# Improve instructions

improve-instructions is a trial start for an owner who asks to tidy the agent instructions file, AGENTS.md or CLAUDE.md. Tidying the file is a change: propose its mode and wait, as AGENTS.md says, open its record with a `## start` section naming improve-instructions, and run the line from `frame`; the rewrite is its build. Edit only outside those markers: never move, rewrite or wrap the block, and keep the owner's `## House rulings` stanza as the work guide describes it.

Greenline's paths and commands for this skill stand on its references page, [references/greenline.md](references/greenline.md): read it when the work lands in the workspace.

Before the rewrite, read [method.md](method.md): the managed block, the core problem, the principles, the output's structure and how to apply them.

## Handoff

Consumes: the agent instructions file, AGENTS.md or CLAUDE.md, outside greenline's managed markers; the repository's linters, hooks and code patterns
Produces: through the change, the file rewritten outside the markers: the identity, the map and the boundaries bare, every command kept, each conditional rule under a heading naming its situation, the managed block untouched
