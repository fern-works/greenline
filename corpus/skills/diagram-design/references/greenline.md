# Diagram design: the practice's mechanics

This page holds where diagram-design's work lands in the workspace and the commands it runs, which `SKILL.md` names by their nouns. Read it with `SKILL.md` when the work lands in the workspace.

## Where its work lands

The workspace's diagrams folder is `.greenline/diagrams/`: a diagram is saved in `.greenline/diagrams/<work-id>/`, named by the change id or the plan name it serves, such as `.greenline/diagrams/2026-10-08-retry-deadline/flow.html`. The project's style guide is `.greenline/diagrams/style-guide.md`; the installed `references/style-guide.md` is the one `greenline sync` owns and never edited.
