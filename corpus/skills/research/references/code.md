# Code

Read this page when the topic's source class is code: how other projects implement the pattern the question names.

1. **Search.** Search code with `gh search code`, narrowed by language, file name or owner, and repositories with `gh search repos`, narrowed by language, licence, topic and recent activity. Its index is not the site's own search and takes no regular expression, so read a result as a lead, never as coverage.
2. **Choose.** Pick two or three implementations that are active and used, not the first hits.
3. **Pin.** Pin each to its full commit, from the result's commit or `git ls-remote`, and read only at that commit, never a moving branch.
4. **Read the licence first.** Read the licence file at that commit before any code, and name it beside the locator; a repository with none is named unlicensed.
5. **Report the pattern.** Say each pattern in your own words with its locator, `owner/repository@commit:path:line`, and at most one quoted line. Take patterns, never code: nothing you read is pasted into the workspace.

Use only the owner's existing `gh` session. Without one, say so and take the web route; never ask for a login or a token.
