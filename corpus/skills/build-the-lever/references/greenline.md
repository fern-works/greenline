# Build the lever: the practice's mechanics

This page holds where build-the-lever's work lands in the workspace and the commands it runs, which `SKILL.md` names by their nouns. Read it with `SKILL.md` when the work lands in the workspace.

## Where its work lands

The check that proves the lever runs through `greenline check -- <command>`. A lever that should not stay in the code is copied into the change's folder, `.greenline/ledger/<id>/`.
